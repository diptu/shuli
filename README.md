A Simple, Fast, and Unified Data Visualization Library for Python.

shuli unifies the strengths of Matplotlib, Seaborn, ggplot2, and D3.js behind one intuitive, Pythonic API.

Designed for simplicity, flexibility, and performance.

---

## Key Features

- **Simple API:** Create beautiful visualizations with minimal code.
- **Grammar of Graphics:** Build composable, layered plots.
- **Statistical Visualization:** Simplify statistical analysis and exploration.
- **Flexible Customization:** Fine-grained control over visual elements.
- **Interactive Graphics:** Support data-driven interactions and animations.
- **High Performance:** C++ core and Arrow-compatible memory architecture.

## Quick Start

```python
import shuli as sh

sh.plot(
    data,
    x="date",
    y="temperature",
    kind="line",
    title="Daily Temperature"
)
```

## Installation

pip install shuli
